# 🎵 Yandex Music: Exact Release Date

> Легковесное расширение для Chromium-браузеров, отображающее точный день, месяц и год выхода альбома или сингла в Яндекс Музыке.

## 📌 Проблема

В стандартном веб-интерфейсе Яндекс Музыки отображается исключительно **год** выпуска релиза. Из-за этого пользователям сложно быстро узнать конкретный день премьеры трека или альбома, приходится проверять сторонние сервисы и дискографии.

## ✨ Решение

Расширение находит год на странице альбома и при наведении курсора показывает аккуратный нативный тултип с точной датой выпуска (например, `Выпущен: 4 июня 2021 г.`).

- **Прямая интеграция:** использует внутренний эндпоинт `api.music.yandex.net/albums/<id>`.
- **Кэширование:** запрашивает данные один раз за сессию для каждого альбома, исключая лишнюю нагрузку на сеть.
- **SPA-ready:** корректно реагирует на внутреннюю навигацию по сайту без перезагрузки страницы (`MutationObserver`).
- **Точное позиционирование:** центрируется строго по цифрам текста года через `Range API`, игнорируя служебные BEM-разделители и псевдоэлементы интерфейса.
- **Нативный дизайн:** стилизован под интерфейс темной темы Яндекс Музыки (размытие фона, акцентные тени, аккуратный указатель).

## 🚀 Установка

1. Склонируй репозиторий или скачай архив с кодом:

   ```bash
   git clone https://github.com/username/yandex-music-exact-date.git
   ```

2. Открой в браузере (Chrome / Edge / Brave / Yandex Browser) страницу управления расширениями:

   ```text
   chrome://extensions
   ```

3. В правом верхнем углу включи тумблер **«Режим разработчика» (Developer mode)**.
4. Нажми кнопку **«Загрузить распакованное расширение» (Load unpacked)** слева вверху.
5. Выбери папку с файлами проекта.
6. Открой страницу любого альбома на [music.yandex.ru](https://music.yandex.ru/) и наведи курсор на год выпуска.
